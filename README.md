# GlowChat

**Tagline:** Connect. Chat. Stay Close.

GlowChat is an original, secure messaging application being developed
from scratch according to its own requirements.

## Initial Release

- Android application only.
- Java and XML.
- PHP REST API.
- Node.js WebSocket server.
- PostgreSQL database.
- Redis for temporary real-time data.
- End-to-end encrypted messaging.
- Separate web administration panel.

## Project Structure

| Directory | Purpose |
|---|---|
| android/ | Android application |
| backend/ | PHP REST API |
| websocket/ | Node.js real-time server |
| admin-panel/ | Web administration panel |
| database/ | PostgreSQL schema and migrations |
| documentation/ | Project specifications |
| deployment/ | CI/CD and deployment configuration |

## Development Principles

- Build everything from scratch.
- Develop and test locally first.
- Keep credentials and secrets outside Git.
- Use version-controlled database migrations.
- Test changes before merging.
- Maintain end-to-end encryption.
- Prepare production deployment for later.
